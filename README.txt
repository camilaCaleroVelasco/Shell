Description of Project:
    CODE CONTAINS fork() MAKE SURE IT IS RUN IN A CLUSTER.
    This is a shell that works like bash. It reads standard input, it changes directory, launches processes (ex: $ cat file1.txt file2.txt), and  redirects standard input and output (ex: $ COMMAND5 arg1 > output.txt < input.txt).

    *** HOW TO COMPILE ***
    Type in command “make”

    ***HOW TO CLEAN***
     Type in command “make clean”

    ***HOW TO RUN***
     Type in command “make run”
